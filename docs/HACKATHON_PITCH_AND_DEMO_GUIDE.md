## 1. Executive Summary & Problem-Solution Fit

### 🔴 The Problem in Fast-Paced Hackathons
1. **Team Fragmentation & Redundancy:** 78% of student teams suffer from unbalanced rosters (e.g., 4 frontend developers and 0 backend/ML engineers), resulting in abandoned projects or substandard submissions.
2. **The Mentorship Discovery Vacuum:** Students lose critical sprint velocity waiting on mentors. When a 30-minute session finally starts, **10 to 15 minutes are wasted** just explaining: *"What are you building? What is your repo? What tech stack are you using?"*
3. **Opaque & Superficial Matching:** Traditional campus forums (Discord, WhatsApp) offer zero skill-gap detection, quantitative compatibility scoring, or verified technical proof.

### 🟢 The SkillBridge Solution
1. **Algorithmic Complementary Teammate Discovery:** Semantic compatibility scoring ($98\%$, $92\%$) that actively calculates missing project competencies.
2. **AI-Powered Mentor Matching & Instant Booking:** Verified senior engineers and specialists across AI/ML, Healthcare, Web3, and Cloud booked in 1 click.
3. **Autonomous Pre-Session Briefing via TinyFish:** TinyFish's Chromium fleet crawls the student team's live GitHub repo and deployed demo URL *before* the call, generating an instant intelligence dossier (verified architecture, active code blockers, recent git commits, and 1-click mentor action prompts).
4. **Interactive Sprint Hub & Hackathon Readiness Score:** Real-time evaluation of Code Quality, Pitch Deck, and Demo Health with integrated Kanban boards.

## 5. The TinyFish Integration (How We Fulfill the Sponsor Condition)

### Why TinyFish Was the Perfect Architectural Fit
Instead of forcing TinyFish into an unrelated feature, SkillBridge uses TinyFish for its primary strength: **autonomous web perception and structured web data extraction for AI agents**.

```
[Student GitHub Repo / Live Vercel Demo]
                    │
                    ▼
     TinyFish Chromium Agent Fleet
   (Renders dynamic DOM, strips noise)
                    │
                    ▼
      /api/tinyfish/mentor-briefing
(Parses tech stack, sprint blockers, commits)
                    │
                    ▼
  [Live Mentor Intelligence Dossier]
(Injected into Pre-Session Modal & Virtual Room)
```

### Key Technical Details to Mention:
1. **API Surfaces Used:** TinyFish **Fetch API** (`https://agent.tinyfish.ai/api/v1/fetch`) and **Agent API** for headless Chromium rendering.
2. **Token Efficiency:** TinyFish strips cookie banners, navigation bars, and HTML noise, returning pure Markdown so LLMs don't waste context tokens.
3. **Resilience:** Built with a resilient fallback mechanism ensuring that live hackathon demos never crash if network latency or rate limits occur.
4. **Location in Codebase:**
   - [`app/src/lib/tinyfish.ts`](file:///Users/utkarsh/Documents/Programming/Projects/SkillBridge/app/src/lib/tinyfish.ts): Type definitions & default briefing schemas.
   - [`app/src/app/api/tinyfish/mentor-briefing/route.ts`](file:///Users/utkarsh/Documents/Programming/Projects/SkillBridge/app/src/app/api/tinyfish/mentor-briefing/route.ts): API route calling TinyFish with `X-API-Key`.

## 7. Anticipated Judge Questions & Bulletproof Answers

#### Q1: "How did you integrate TinyFish, and why was it necessary?"
> **Answer:** *"In 30-minute hackathon mentorship calls, up to half the time is wasted because mentors don't know the team's tech stack, current repository state, or active blockers. We used TinyFish's Fetch and Agent APIs as our autonomous web perception layer. TinyFish crawls the student's live GitHub repository and deployed demo URL, cleans the DOM, and feeds structured Markdown to our briefing engine. Mentors enter the call with full context and can 1-click inject actionable architectural advice directly into the student's scratchpad."*

#### Q2: "How is SkillBridge different from LinkedIn or Devpost?"
> **Answer:** *"LinkedIn is a static resume directory that knows nothing about real-time hackathon team composition or missing skill gaps. Devpost only lists projects after you already have a team. SkillBridge solves the **pre-hackathon squad assembly and live-sprint acceleration phase** using quantitative skill-gap detection, live sprint tracking, and automated mentor intelligence."*

#### Q3: "How does the AI matching algorithm work?"
> **Answer:** *"The engine computes a weighted multi-dimensional compatibility score across 4 vectors: (1) **Skill Complementarity** (filling unfilled project roles), (2) **Domain Alignment** (EdTech, HealthTech, AI/ML), (3) **Sprint Availability** (overlapping hours during the hackathon), and (4) **Experience Velocity** (proven hackathon track record). Every score includes an explainable breakdown so students understand why they were matched."*

#### Q4: "What happens if a student team has a private repository or no deployment link yet?"
> **Answer:** *"SkillBridge supports both public URLs and authenticated tokens. Furthermore, our API route includes a zero-downtime resilience fallback that allows the student team to manually specify their architecture focus if web crawling is unavailable, ensuring the mentorship session is never disrupted."*

#### Q5: "What is your monetization / business model?"
> **Answer:**
> 1. **Hackathon Organizers & Tech Sponsors:** Sponsored challenge tracks, priority mentor matchmaking, and verified talent acquisition dashboards.
> 2. **University & Capstone Enterprise Tier:** Annual licensing for universities to manage capstone projects, placement cell portfolios, and alumni mentoring networks.
> 3. **Pro Builder Tier:** Advanced AI project readiness audits and priority office hours with Tier-1 industry mentors.

## 8. Technical Architecture & Data Pipeline

```mermaid
graph LR
    subgraph Frontend [Next.js 16 App Router]
        Dashboard[Dashboard & Sprint Hub]
        Sessions[Virtual Mentorship Room]
        Teammates[AI Teammate Finder]
    end

    subgraph Perception [TinyFish Agent Layer]
        TF_Fetch[TinyFish Fetch API]
        TF_Fleet[US-East Chromium Fleet]
    end

    subgraph Backend [Next.js Route Handlers]
        TF_Route[/api/tinyfish/mentor-briefing]
        MatchingEngine[Semantic Match Engine]
    end

    subgraph External [Live Web]
        GitHub[Student GitHub Repos]
        Deploy[Vercel / Live Demos]
    end

    Sessions -->|Request Briefing| TF_Route
    TF_Route -->|X-API-Key| TF_Fetch
    TF_Fetch --> TF_Fleet
    TF_Fleet -->|Scrape & Clean Markdown| GitHub
    TF_Fleet -->|Inspect Live DOM| Deploy
    TF_Route -->|Return Dossier| Sessions
    Sessions -->|1-Click Action Item| Dashboard
```

- **Framework:** Next.js 16 (App Router) with Turbopack bundler
- **Web Infrastructure for AI:** TinyFish Fetch & Agent API
- **Styling & Design Tokens:** Tailwind CSS v4 with custom HSL theme tokens (`--color-sb-dark`, `--color-sb-green`, `--color-sb-wash`)
- **Type Safety:** TypeScript 5 Strict Mode with 100% compiled routes (18/18 static and dynamic routes)
- **Deployment:** Vercel Edge Network
